# Articulem

Тёмный журнал статей с регистрацией, написанием материалов, подпиской на авторов и **модерацией через админ-панель**. Статья становится видимой в общей ленте только после одобрения администратором.

Стек: **Next.js 14 (App Router) · TypeScript · Prisma · PostgreSQL**. Авторизация — на JWT в httpOnly-cookie (jose) с хешированием паролей (bcrypt). Деплой — **Vercel**.

## Возможности

- Регистрация и вход. При регистрации в БД **автоматически создаётся и заполняется** профиль пользователя (инициалы, цвет, биография).
- Создание статей через редактор с живым предпросмотром. Новая статья получает статус «на проверке».
- **Админ-панель `/admin`**: очередь модерации, кнопки «Одобрить» / «Отклонить» (с причиной). Только одобренные статьи видны в ленте, категориях, популярном и у авторов.
- Чтение статей, лайки, комментарии.
- Подписка на авторов (follow), счётчики подписчиков.
- Лента с поиском, сортировкой и фильтром по 7 категориям; разделы «Категории», «Популярное», «Авторы», «Профиль» с вкладками (опубликованные / на проверке / понравившиеся).

## Роли

- `USER` — обычный пользователь (по умолчанию при регистрации).
- `ADMIN` — модератор. Создаётся скриптом сидирования; видит пункт «Админ» в шапке и страницу `/admin`.

## Быстрый старт локально

```bash
npm install
cp .env.example .env          # впишите DATABASE_URL, DIRECT_URL, JWT_SECRET
npx prisma db push            # создаёт таблицы по схеме
npm run seed                  # наполняет БД: админ + авторы + статьи
npm run dev                   # http://localhost:3000
```

Сгенерировать секрет: `openssl rand -base64 32`

После сидирования вход администратора: **admin@articulem.app / admin12345**
(значения берутся из `ADMIN_EMAIL` / `ADMIN_PASSWORD`, можно переопределить в `.env`).
Демо-авторы: `maria@articulem.app`, `artem@articulem.app` и т. д. — пароль `author12345`.

## Структура

```
prisma/schema.prisma   модель данных (User, Article, Comment, Like, Follow)
prisma/seed.ts         наполнение БД
src/lib/               prisma, auth (JWT/bcrypt), actions (мутации), queries, theme (дизайн-токены)
src/components/         навбар, карточки, формы, кнопки лайка/подписки, админ-действия
src/app/               страницы App Router + API авторизации
middleware.ts          защита /create, /profile, /admin
```
